# Public repository scope

[Bharathraj009/bankops-ai](https://github.com/Bharathraj009/bankops-ai) contains the
banking service, reliability agent, operations dashboard, reconciliation workflow,
configuration templates and authored verification records. Published baseline
[`36a88e8`](https://github.com/Bharathraj009/bankops-ai/commit/36a88e892c10a7ffba6660a9096b42d5a65f812b)
includes the documentation quality audit following implementation commit `8dff277`.
See [publication verification](PUBLICATION_READINESS.md).

The public checkout has separate sanitized history. Private banking responses,
credentials, dumps, logs, caches, installed dependencies and raw generated evidence
are excluded. Ignored `.publication/` files are local review aids. The screenshot
is a static interface preview using no service requests or customer data.

[Dated verification records](docs/verification/README.md) preserve implementation,
publication preparation and review evidence. Their pending-approval statements
refer to those recorded reviews. The [README limitations](README.md#deployment-scope-and-limitations)
state the current deployment, inference, data and integration boundaries.
